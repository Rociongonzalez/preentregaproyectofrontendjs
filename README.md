# Pre-Entrega 2: Proyecto Final Front-End

Este repositorio contiene el proyecto para la segunda pre-entrega del curso de Front-End. Es un sitio web estático de una sola página (Landing Page) para una tienda ficticia.

## Propósito

El propósito de esta página es aplicar los conocimientos adquiridos en HTML semántico, CSS, y diseño responsivo (Flexbox y Grid) para construir una interfaz de usuario coherente y adaptable a distintos dispositivos.

## Tecnologías Utilizadas

* **HTML5 Semántico**: Se utilizó una estructura semántica clara (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* **CSS3**: Para todos los estilos, incluyendo:
    * **Google Fonts**: Para la tipografía general.
    * **Flexbox**: Para organizar la galería de "Productos" de forma responsiva.
    * **Grid**: Para maquetar la sección de "Reseñas".
    * **Media Queries**: Para adaptar la navegación y la sección de "Contacto" a dispositivos móviles.
* **Formspree**: Se integró un formulario de contacto funcional que envía los datos a un endpoint de Formspree.
